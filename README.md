# 🧪 Feureau's Math Lab

An interactive web-based educational tool for exploring **mathematics** through visualizations and hands-on problem-solving. This lab brings abstract mathematical concepts to life with animated widgets and step-by-step explanations.

---

## 📚 Overview

Feureau's Math Lab is a collection of standalone HTML applications designed to help learners:
- Understand the fundamental principles of **combinatorics**
- Visualize how combinations grow exponentially
- Experiment with different categories and items interactively
- See mathematical relationships through dynamic, colorful animations

Built entirely with **HTML, CSS, and JavaScript** — no frameworks or dependencies required. Just open in any modern browser!

---

## 🚀 Features

### 1. **Combinatorics Problem Explorer** (`combinatorics.html`)
The classic "Outfit Dilemma" interactive widget that proves the fundamental counting principle:
- Select items from different categories (shirts, pants, shoes)
- Combine them visually with animated flying clones
- View results in 2D grid or 3D layered format
- Fill all combinations automatically with one click
- See the math: if you have 4 shirts × 3 pants × 2 shoes = **24 possible outfits**

### 2. **N-Combinatorics Lab** (`N-Combinatorics-Lab.html`)
An advanced exploration tool that demonstrates exponential growth in combinations:
- Create unlimited custom categories with customizable item counts
- Visualize how the total explodes (e.g., 3 × 4 × 5 = 60 combinations)
- Interactive network graph showing connection paths between all nodes
- Multiple viewing modes:
  - **Step-by-step**: Reveal one combination at a time
  - **Play mode**: Watch animations unfold
  - **Peek mode**: Highlight all revealed connections
  - **Speedrun mode**: Flash everything instantly
- Zoom, pan, and explore the network in detail

### 3. **Future Modules** 📐 🔢
The lab is designed to expand with:
- Geometry proofs and visualizations
- Number theory explorations (primes, modular arithmetic)

## 🛠️ How to Use

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No installation required — this is a **static website**

### Getting Started
1. Clone or download this repository
2. Open `index.html` in your web browser
3. Click on any module to start exploring!

### Keyboard Shortcuts (N-Combinatorics Lab)
- **Mouse drag** from node ports → Draw connection paths
- **Scroll wheel** → Zoom in/out
- **Double-click** empty space → Fit view to content
- **Escape** → Cancel active actions
- **Touch devices**: Pinch to zoom, drag to pan
